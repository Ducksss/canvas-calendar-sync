# README visual assets

These assets belong to this project and are stored in Git so the README does not
depend on temporary image-hosting links. No asset contains real coursework,
account identifiers, credentials or screenshots of a user's calendar.

| Asset | Purpose | Provenance |
| --- | --- | --- |
| `hero.png` | Conceptual coursework-to-calendar cover | Original illustration generated with the built-in imagegen tool |
| `logo.svg` | Small calendar/forward-arrow project icon | Original editable SVG; not an official Canvas or Google logo |
| `workflow.svg` | Accurate discovery → plan → mutation sequence | Original editable SVG based on the reconciliation code |

The cover is an illustration, not product UI or evidence of a live sync. Workflow
labels also appear in README prose and alt text. SVGs have explicit backgrounds,
titles and descriptions for legibility on light and dark GitHub themes. They
contain no scripts, external font imports or embedded remote images.

## Editing

Edit SVG source directly and render it before committing. Preserve the one-way
flow, complete-preflight gate, dry-run stop and create/update-before-delete order.
Inspect at README width and on smaller screens. Keep all source text readable
without relying on color alone. Keep raster assets reasonably sized; never
replace an illustration with a real student screenshot without explicit consent.

Original assets are provided under the repository's MIT license to the extent
copyright applies. Third-party badges are served by GitHub and Shields.io;
Best-README-Template is credited in the README and is not the source of this artwork.

## Cover generation prompt

Built-in imagegen, generation mode (no reference images, no external API-key CLI):

> Use case: stylized-concept. Asset type: wide GitHub README cover illustration for
> Canvas Calendar Sync, an open-source local macOS command-line tool that transfers
> coursework deadlines into Google Calendar. Primary request: an original polished
> editorial illustration showing coursework cards moving along one clear left-to-right
> path into an orderly calendar, with a small subtle lock suggesting local credential
> storage. Style: restrained contemporary dimensional paper illustration, clean
> shapes, generous whitespace and crisp edges, sophisticated rather than cartoonish.
> Wide 3:1 landscape composition for a README, objects comfortably inside margins,
> suitable on both light and dark GitHub pages with its own clean background.
> No text, letters, numbers, logos, official product branding, watermarks, humans,
> fake application UI or screenshot framing. Keep calendar cells abstract.
> The illustration is conceptual, not an image of an actual application.
> No bidirectional arrows.
